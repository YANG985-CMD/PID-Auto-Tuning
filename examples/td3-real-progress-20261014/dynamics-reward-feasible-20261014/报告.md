# PI 有效响应、奖励与可行动作表示诊断

本次仅使用既有 42 个实机 boot，没有连接硬件、启动电机或下发参数。

## PI 指令与有效模型

v27 源码显示，当前积分状态和最近一次 PI 边界误差可以还原该边界的 Iq 指令：单精度 `clamp(Kp*last_PI_error + integral_output,-3,3)`。原生成代码的 35000 组主机检查误差为 0，若误用当前瞬时转速误差则会不同。用 41790 个真实快照还原指令，不代表独立测量实际 Iq；快照间约 20 ms 内的电流环与 PI 状态仍未记录。

根据完整、因果 Hall 电气周期计算的速度只用于响应诊断，原始 Hall 主指标不改变。将速度导数拟合为当前周期平均速度及还原 Iq 指令的线性函数，训练/验证分别使用冻结的 21 个 boot。系数符号符合阻尼为负、指令增益为正；验证速度导数 RMSE 仍约 390.25 rpm/s，相比均值先验误差减少约 5.76%。这不是电机性能改善：指令由反馈生成、区间内真实输入缺失，未辨识真实 J/B，也没有批准该模型做策略滚动或控制训练。

## 奖励核对

5686 个窗口的原奖励全部分解复现，误差小于 1e-12；没有改奖励权重。按 boot 等权，验证集中电流项约占 27.68%、速度项约占 72.32%。因此不能简单把小收益归因于电流项主导。较小电流变化的量化问题仍存在，但不证明它是唯一原因。

## 动作梯度问题与修正

重建原种子 7/17/27 的初始网络后发现，旧“绝对目标再裁剪到当前步长”表示，让约 51.1%–58.0% 采样权重对应样本的动作梯度为 0。完成原训练后，这个比例降为约 16.8%、0.66%、2.43%，所以它只是训练困难之一。

新增离线可行区间表示：原始 Actor 输出区间位置 [-1,1]，经当前实测 Kp 和原步长限制，映射成 Critic 使用的绝对动作坐标。真实回放动作、奖励和保护边界保持。1792 个实际动作逆映射/回放通过，增益误差最多一个浮点末位；内部位置到可行动作的梯度在区间内部严格为正，无直通近似导数。Ki 输出恒为 0。

新策略保存为明确的自定义 TD3 检查点：Actor 为区间位置坐标、双 Critic 为绝对增益坐标；未导出混淆坐标的原生 agent，也未生成 MCU 代码。原始基准目标初始化与新的可行区间中点初始化不同，比较记录这一限制。

## 离线训练对照

同一 300 ms 视图训练种子 7/17/27，保存 1800 次双 Critic 更新迭代、900 次 Actor 更新。与原训练逐一核验：相同回放、奖励、采样动作计数、切换计数、初始 Critic 拟合以及绝对动作单位下的目标噪声。新映射最终输出梯度为零的比例为 0，优化问题已被解决。

三个新候选的单次动作模型预测速度收益约 0.1067%、0.1010%、0.1011%；原同视图候选约 0.0926%、0.0177%、0.0671%。这些是历史验证状态上的单次预测，未校准模型不确定性，不是 PI/Actor 的闭环实机比较。改善了优化一致性，没有证明达成 5%。因此候选均未通过、不下发 Actor，保持基准 PI 与 Ki=0.00144。

`feasible-gradients-300ms-v2.json` 是权威初始网络梯度报告；早期 `feasible-gradients-300ms.json` 将全零目标作初始化参照，不能当作逐种子实际网络的初始梯度。两者均保留且明确区分。
