# STM32G431 比较器与 TIM1 Break 信号验证

2026-10-11，用户确认 24V 已物理断开、USB/STLink 仍供电后，Codex 编写并在实际 G431 的 SRAM 中运行独立诊断程序。**真实比较器到 Break 状态标志的路径通过，尚未完成按安培校准的过流保护验收。**

## 本次结果

| 检查 | 结果及证据范围 |
|---|---|
| 实际 MCU 诊断 | 8/8；改变 DAC3 CH1 的内部比较阈值，对照 COMP1/PB1 与 TIM1 BIF |
| 阈值 4095 和 3000 | COMP1 为低，初始 BIF=0 |
| 阈值 0 | COMP1 为高，TIM1 BIF=1（SR=128），真实硬件路由已观测 |
| 恢复阈值及清硬件标志 | COMP1 回到低、SR=0；独立诊断程序的故障仍为 1 |
| 静止输入交叉区间 | DAC 码 2033～2034；不是保护电流校准，不能当成新的运行门槛 |
| 输出隔离 | 17 次采样均保持 MOE=0、CCER=0、CEN=0，六个功率引脚为复位模拟模式；未配置或输出相位 PWM |
| RAM 资源 | 镜像 4,448 B，观测栈 40 B、底部围栏完整；仅覆盖该诊断路径 |
| 总流程 | 371,467 周期，16MHz 下约 23.2ms，包含多次 1ms 等待；不是封波延迟 |
| 收尾 | 核心暂停，TIM1 CR1/CCER/BDTR=0、GPIO 时钟关闭；完整 128KB Flash 逐字节未变 |

结构化证据见 [summary.json](../examples/stm32g431-comp-break/summary.json)。没有使用 CAN、串口、真实电流探索或 TD3 增益。原 Flash 应用没有恢复。

第一次执行在外设测试前被时钟前置检查拒绝：诊断代码错误地预期 HSI 的 SWS 为 0，读到的实际编码是 0x4。Codex 对照 CMSIS 修正，重新构建后通过；首次退出也确认核心暂停、PWM 关闭、Flash 未变。此失败属于诊断程序检查错误，不是板卡过流保护失效。

## 同时改进了实际接入代码

原工程虽然有 COMP1 和 TIM1 Break 配置，但未找到应用层过流锁存回调；启用 NVIC 不代表 BIE 或 COMP EXTI 已启用。因此，实际锁定适配层的 1ms 任务新增读取 BIF/B2IF/SBIF，检测后执行已有禁能并保持软件故障，不依赖回调才能发现硬件标志，也不自动清故障。

- 实际适配层软件测试 **24/24**：19 项适配层检查与 5 项 RAM 入口检查，含无回调的三种 Break 标志、硬件标志清除后仍锁存、STOP/BEGIN 不恢复输出。
- 新诊断入口软件检查 **14/14**：拒绝缺失断电确认、镜像变更、错误极性、自动恢复、没有真实 BIF、输出隔离失败，以及异常后的复位暂停/Flash 比较。
- 修改后的完整 FOC 接入副本 **45 个编译单元重新链接成功**，ROM 44,768 B、RAM 8,176 B（含 4KB 栈）；原私有工程 1,062 个源码/头文件/项目文件的指纹检查通过，源码未变。

**完整 HAL/FOC 接入固件仍未上板执行或烧录。** 上述故障锁存的实际适配层检查使用软件替代 HAL/寄存器；板上执行的是独立诊断程序。两者的证据不能合并成“完整电机保护已验收”。

可复用流程见 [skill 操作说明](../skills/motor-td3-serial-tuning/references/g431-comp-break.md)，包括固定镜像构建、断电条件、寄存器轨迹校验和异常收尾。

## 仍需完成的验证

当前诊断全程不把 MOE 设为 1，所以没有验证 MOE 从 1 自动清零，更没有验证功率引脚的关闭电平、真实封波延迟、相电流增益及三相正负电流覆盖。DAC 3000 按此前标称偏置 2048 推算约 +20.9 A，仍不能当成 3 A 保护。

下一阶段要先确定该电机/驱动器的实际保护目标，再做受控电流/采样校准和输出关断验收。现有文件与空载试转记录不够批准完整模糊 PI 增益集合或 TD3 动作空间；热保护、独立硬件看门狗、无扰参数切换等缺口仍保留，能力位仍为 0。

ST [RM0440](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)说明 Break 置位状态标志，中断请求取决于 BIE，自动输出恢复取决于 AOE。本次按这些机制观察 BIF，没有通过软件写入 BIF 或 EGR.BG 伪造比较器触发。
