# 17.SpeedLoop 速度 PI 接入验证

日期：2026-10-11。用户指定已正常运行的 `17.SpeedLoop`，Codex 以它为工程基准完成参数接入代码与离线验证。

本文保留首个 44 单元 PI 接入阶段的记录；随后现有 CAN 已接到 PI 边界，最新 49 单元构建见 [CAN→PI 接入](speedloop-can-pi-integration.md)。

## 定位与修正

- 模糊 PI 原本在约 10kHz ADC 回调中持续改写 Kp/Ki，外部动作会被覆盖。新增默认模糊、固定参数、外部调参三种模式，参数仅由当前模式的所有者写入。
- 速度 PI 实际每 1ms 执行，并使用上一输入积分。新参数在这一真实边界成对生效；Ki 保持连续增益，模型只乘一次积分周期。
- 修正切换瞬间积分状态，保持 `Kp × error + integral` 连续；保留原模型 reset 优先、`±3` 饱和与抗积分饱和。
- 提供实际参数、应用序号/时间及切换前后状态。排队动作不算已应用；新动作也不能提前延长旧动作期限。
- 原工程在启动 ADC 后才初始化模糊控制器。私有副本改为模型、模糊与参数所有者初始化完成后再开放 ADC 触发。

## 工程基准与当前限制

采用 `17.SpeedLoop` 的基础 Kp/Ki、电流名义换算、10 次启动校零以及 COMP1→TIM1 Break 配置。DAC `3000` 是码值，Iq `±3` 是控制器指令限幅；本次没有测出过流跳闸电流，也没有取得例程未提供的热限值。

本次私有复核镜像保留 FOC 和 CH4 采样代码，但移除相桥启动，USER3 仅停机；没有接通 CAN 增益命令或 TD3 Actor，没有烧录到板上。实际参数回传、保护监督和运动门控仍须接入同一份固件。主机数值一致性与链接成功不等于实机闭环或保护验收。
