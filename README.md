# PID 参数自整定：AI 驱动的四种可移植方法对比

本仓库使用 AI（Codex）自动完成参数调节及相应的训练、评估，以电机速度环为例，对比 **AI skill 有界搜索、模糊 PID、神经网络 PID 和 TD3 Actor** 四种 PID 参数自整定方法。当前示例采用 PI 形式（Kd=0），调整 Kp、Ki，固定 PI 作为比较基线。

**四种方法都可以由使用者借助 AI 移植到自己的控制对象和板卡。** AI skill 有界搜索与 TD3 Actor 是本仓库重点构建的创新工程方案；目标条件满足后，Codex 可继续完成目标工程接入与部署。

## AI 在四种方法中如何调参

Codex 根据响应数据选择或修改配置、运行程序并分析结果；Python/MATLAB 执行数值搜索、模糊推理和网络梯度更新。设计阶段调整方法的超参数，运行阶段由所选方法计算 Kp、Ki。

| 方法 | AI 具体调什么、怎么调 | 如何执行与判断结果 |
|---|---|---|
| **AI skill 有界搜索** | GPT-6.1-sol 读取串口采集的波形摘要，根据误差、过冲、电流和饱和情况，提出边界内的 Kp/Ki 候选，并调整下一轮搜索方向与步长。 | Python 检查候选、通过串口下发并回读实际参数；同工况复测后保留较优参数或回退。表格中的仿真版本采用先粗搜、再局部细搜的确定性实现。 |
| **模糊 PID** | Codex 根据响应设计和迭代误差归一化尺度、隶属函数断点、规则表及增益映射系数，运行仿真比较各版设置。 | 当前版本使用 7×7 规则，按输入隶属度的乘积激活规则，再加权平均得到增益修正。Codex 根据跟踪误差、过冲和控制代价决定下一轮如何修改配置。 |
| **神经网络 PID** | Codex 准备状态与目标增益样本，选择输入尺度、网络结构、学习率和训练轮数，调用 Python 训练并分析验证结果。 | Python 通过反向传播更新权重，当前网络学习模糊 PID 的增益调度。Codex 同时比较验证损失和闭环指标，再调整配置、重新训练；运行时输出有界增益，超出训练范围时回退。 |
| **TD3 Actor** | Codex 审计动作与后续响应的对应关系，配置状态、奖励、Actor/Critic 学习率、噪声、批量大小和更新次数，调用 MATLAB 训练并比较候选。 | MATLAB 执行 TD3 权重更新；Codex 组织关闭探索的固定策略评估，依据跟踪误差、电流、过冲、饱和及故障筛选候选，并在目标条件满足后导出 Actor、接入工程和部署验证。 |

当前比较脚本复现的是代码中保存的一组模糊规则与网络超参数配置；移植时，Codex 根据目标数据修改配置、重新运行或训练，再比较结果。[各方法的调整步骤、默认参数和代码入口](docs/pid-self-tuning-methods.md#四种自整定方法的工作流程)见详细说明。

## 四种方法的结果对比

以下表格对应当前代码保存的仿真/离线评估结果。AI 搜索、模糊 PID 和神经网络 PID 由比较脚本计算，TD3 行读取 MATLAB 固定策略评估摘要。

| 方法 | 平均归一化 RMSE | 平均峰值电流 (A) | 平均过冲 (rpm) | 饱和占比 | 故障 |

| AI skill 有界搜索 | 0.171898 | 2.3806 | 0.799 | 0.0072 | 0 |
| 模糊 PID | 0.165461 | 2.7177 | 0.000 | 0.0194 | 0 |

在这组结果中，神经网络 PID 的平均 RMSE 最低；AI skill 有界搜索的平均峰值电流和饱和占比最低。结果用于比较跟踪性能与控制代价，未形成四种方法的实机排名。
