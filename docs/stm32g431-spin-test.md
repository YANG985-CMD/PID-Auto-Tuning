# STM32G431 原固件空载试转记录

日期：2026-10-10

## 试验对象

- 控制器：STM32G431RBT6 电机控制板。
- 功率：24 V 母线，电源限流 3 A。
- 电机：资料标注为 24 V、Hall 120°、额定约 1300 rpm 的三相电机。
- 固件：板上原有的 `17.PID control speed` 构建；试验前通过 STLink 只读核对，未烧录和未改写 Flash。
- 启动参考：原固件固定 `SpeedRef=1000`，通过板上 USER3/PC13 使能三相 PWM。

## Codex 做了什么

Codex 通过 STLink 恢复原固件运行，并从 MCU SRAM 和 TIM1 外设寄存器实时读取母线电压、三相电流、Hall 状态、Hall 速度和 PWM 使能状态。Codex 对采样结果做了趋势判断：Hall 六状态连续有效、速度是否达到参考值、母线是否稳定、相电流是否异常以及 TIM1 Break 是否触发。试验结束后，Codex 执行系统复位并暂停，核对 `TIM1_CCER=0`、`TIM1_BDTR=0`，确认三相 PWM 已关闭。

## 观测结果

| 项目 | 观测 |
|---|---|
| 母线电压 | 约 24.0–24.36 V |
| Hall 状态 | 1–6 状态连续出现，没有看到非法状态 |
| 速度 | 约 950–1050 rpm，围绕 1000 rpm 运行 |
| 相电流采样 | 约在 ±1.1 A 内，未见持续上升趋势 |
| PWM | 运行时 CH1–3 及互补输出使能；停机后 `CCER=0`、`BDTR=0` |
| 过流保护 | 试验期间未观察到 Break 触发 |
| Flash | 未写入；原固件保持不变 |

## 限制与结论

这次证明了原有 Hall FOC 固件可以在空载、24 V/3 A 条件下使电机运行到约 1000 rpm，也证明 Codex 可以实时读取板上运行数据、判断运行结果并执行安全停机。此次没有发送 TD3 增益，也没有让 TD3 接管速度环；因此不能把这次试转结果当作 TD3 闭环训练或部署验收。

当前原固件的 UART3（PB10/PB11）只输出二进制遥测，启动由 USER3 按键完成，和仓库的 CRC/租约 TD3 协议不同。要进行 TD3 实机训练，仍需先在固件中加入原子增益写入、应用回读、失联租约、故障锁存和独立停机，并在相同工况下比较固定 PI 与 TD3。
