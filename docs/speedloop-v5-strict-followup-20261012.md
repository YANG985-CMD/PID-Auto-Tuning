## 目标噪声为什么值得检查

本机 MATLAB R2024b 原生 TD3 的目标动作噪声标准差为 sqrt(0.2) ≈ 0.4472，截断到 ±0.5；这是训练时构造目标 Q 的平滑噪声。本轮没有把噪声发送给电机。[MathWorks TD3 选项](https://www.mathworks.com/help/reinforcement-learning/ref/rl.option.rltd3agentoptions.html)

真实日志的 Ki 归一化变化范围仅为 ±0.25。在 Actor 输出为 0 的参考情形下，默认截断高斯噪声约有 57.6% 概率超出这一全局区间。这是用于解释潜在外推的分析，不是每个状态下动作支撑范围的证明。小噪声设置为标准差 0.05、截断 ±0.1；所有实际电机动作和工程映射保持原样。

行为克隆权重也单独比较 2.5 / 0.25。MathWorks 的该参数调节标准 RL 损失相对于克隆损失的权重，因此减小它会让克隆项相对更强，不能把参数增大解释为克隆约束更强。[MathWorks 行为克隆选项与损失定义](https://www.mathworks.com/help/reinforcement-learning/ref/rl.option.rlbehaviorcloningregularizeroptions.html)

## MATLAB 四组实际训练

四组使用完全相同的严格训练集、验证集、Actor / 双 Critic 结构、归一化、随机种子 7/17/27、80 步更新和 gamma=0.99。gamma 是每个合并决策的折扣，窗口持续时间可变，状态包含 elapsed_ms。每个原始经验只进入一次回放池；随机小批次重复使用经验不计为新增实机数据。

| 目标噪声 std / clip | BC 权重 | 三个种子的平均 Kp 动作 | 验证状态上 Critic 平均分歧 |
|---|---:|---|---:|
| 0.4472 / 0.5 | 2.5 | +0.008154 / −0.015955 / −0.013821 | 0.017050 |
| 0.05 / 0.1 | 2.5 | +0.010722 / −0.017027 / −0.012734 | 0.006558 |
| 0.4472 / 0.5 | 0.25 | +0.008210 / −0.015201 / −0.011586 | 0.017047 |
| 0.05 / 0.1 | 0.25 | +0.010795 / −0.014413 / −0.010341 | 0.006559 |

12 个 Actor 和 24 个 Critic 权重均实际更新，JSON 导出与 MATLAB 权重逐项一致。总共 960 步。每个检查点都有单独 SHA；对应 Q、当前 Critic 的 Bellman 自洽残差和行为动作误差已公开。

较小噪声使平均双 Critic 分歧降低 61.5%，但 Kp 种子间的方向差异没有消失。这个指标描述网络之间的一致性，不能换算成电机 RMSE 改善。平均建议对应基准 Kp 约 +0.09% 至 −0.14% 的单次变化，方向符号也不能独立证明策略有实际控制效果。

训练后对本批证明为 RunStage 的状态生成建议，并记录实际参数、候选参数和检查点 SHA。建议属于离线回放，所有 hardware_writeback=false。本轮没有测量新网络的 45 ms 实时延迟。

为检查 80 步更新是否过短，另行预定小噪声 / BC=0.25、种子 7/17/27、每种子 400 步。三个模型均从相同种子重新初始化，没有增加实机数据，也没有按符号变化自适应加时。

|---|---:|---:|
| 7 | +0.039432 | −0.064480 |

## 剩余问题与当前决策

1. **保持参数的样本占多数。**128 个训练窗口中只有 12 个真实 Ki 变化决策；维持同一 Ki 的窗口提供响应，但不会增加新的扰动方向。
2. **有限试验中的 Ki 直接作用很弱。**按 20 ms 遥测重放 ΔKi × 实测误差的积分项，探测轮的净增量约 0.00056–0.00062 个模型输出单位。它不是全速率积分、反事实电机仿真或测得的相电流差，不能证明改变 Ki 会改善转速。
3. **基准重复波动和启动末尾阶段影响评价。**当前只有启动后约 0.6 秒的闭环证据，未证明稳态、未训练速度或负载条件。
4. **新检查点没有对应实机比较。**旧 Actor 的失败 A/B 只绑定旧 SHA 与 Kp-only 掩码，不能转移到新模型。新网络的物理性能字段仍为 null。
5. **长期价值的续接支撑不足。**128 个训练窗口中，57 个 next_state 没有同一 boot 下时间精确相接的后续训练窗口，包含 34 个片段截尾。next_state 本身是实际测量，不代表丢帧；数据清理或试验结束后，没有对应的下一动作响应进入这个回放集。当前不伪造终止状态，原生训练继续 bootstrap。gamma=0.99 的价值折扣半衰期约 69 个决策，远长于这些实测片段。这是需要检查的外推来源，不能仅由当前两个 Critic 彼此接近证明估值准确。

下一项改进应审计连续响应片段、截尾目标和动作作用是否可辨识，再决定是否设计新的有界探测。当前不会为达到一致方向继续增加梯度次数，也不会自动追加本批 18 秒运动预算。

当前仍使用基准 PI，Ki=0.00144。所有新模型的部署许可和性能声明许可保持 false；普通温度门、独立电流标定要求和 FOC / 过流 / 失联 / 停机路径保持原样。Codex 分析训练结果、拒绝缺少证据的候选，并管理日志和部署接口；网络权重由 MATLAB 更新。达到严格样本门槛不等于允许烧录 Actor。
