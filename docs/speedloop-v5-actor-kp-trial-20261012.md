# 2026-10-12：固定 Actor Kp 单次实机试验

## 做法

在实时 MATLAB 旁路验证通过后，Codex 启动同一份 g431-speedloop-pi-motion-v5 固件和同一 TD3 检查点。每次 MATLAB 建议绑定到当前 boot_id/seq/t_us，只应用 Kp；Ki 固定为 0.00144。桥接仍有 45 ms 决策期限，实际 Kp/Ki 由板端回读确认，最后由 STOP 和硬件输出读回收尾。

## 结果

| 指标 | 基准 PI | Actor Kp |
|---|---:|---:|
| 目标速度 | 1000 rpm | 1000 rpm |
| 完整遥测 / 输出使能 | 148 / 140 | 148 / 140 |
| 实际增益命令 | 54 | 53 |
| Actor Kp 命令 | 0 | 52 |
| 末段窗口 RMSE | 160.788 rpm | 136.624 rpm |
| 峰值名义电流 | 1.032715 A | 1.076660 A |
| 峰值 Hall 转速 | 1782.531 rpm | 1630.789 rpm |
| 故障 | 0 | 0 |
| STOP、六路输出、核心 | 通过、关闭、暂停 | 通过、关闭、暂停 |

Actor 试验中 Kp 从基线附近逐步增加到约 0.00352，Ki 始终为 0.00144。建议和实际应用序号、时间均经过校验。

## 结论边界

Actor 试验的 RMSE 比基准试验低 24.164 rpm，峰值名义电流高 0.043945 A，峰值 Hall 转速低 151.742 rpm。这是同样预算下的单次观察；两种策略都只有一次实机试验，窗口包含启动和切换过程，电流换算尚未独立标定。因此仓库将 performance_claim_allowed 保持为 false，不把这个结果发布为 TD3 已经优于 PI。

完整原始文件和哈希见 examples/speedloop-v5-real-20261012/realtime-actor-kp-20261012。本试验没有改变温度门或普通部署门槛。
