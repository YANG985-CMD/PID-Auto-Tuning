# Codex 在 STM32G431 上的 Actor 验证

日期：2026-10-10。此报告公开计算验证与资料检查结果，不包含用户私有固件、板卡唯一序列号、供电照片或原手册文件。

## 板卡依据与安全检查

用户指定的《STM32G4开发板原理图.pdf》为 Euler STM32G431 电机板，对外原理图 V1.0（2023-09-03）：

| 项目 | 原理图/资料中的信息 |
|---|---|
| MCU | STM32G431CBU6，Cortex-M4F |
| 三相驱动 | FD6288T + BSC0702LS MOSFET |
| PWM | PA8/PA9/PA10；互补 PB13/PB14/PB15 |
| SWD | PA13 SWDIO、PA14 SWCLK |
| USART3 | PB10 TX、PB11 RX |
| 电流采样 | 三路 5mΩ 分流电阻，经运放采样 |
| 电源 | VDC 经 DC/DC 产生驱动和逻辑电源；接线极性须核对 |

手册 V13.1 第 10～11 页注明 18～38V、0～10A，并提示持续输入电流超过 4A 需要散热；测试手册第 3 页使用 12～38V、0～8A。不同版本范围有差异，不能用这些表格直接确定本机相电流保护或实验阈值。

手册第 11、15 页强调 VDC/GND 极性，第 28 页有例程取消硬件过流配置的说明。另一个所查 Hall 例程的 TIM1 已配置 COMP1 Break、死区及禁止自动恢复；比较器/DAC 阈值、启动、故障锁存和实际停机效果仍须按具体编译固件核对。这些资料检查不等于当前板上保护已经验收。

用户报告电源规格为 24V、3A，随后确认断开功率电源、控制板仍有供电。本次依赖这项现场确认；未把 3A 当作已验证的相电流保护值或可编程电源限流设定。

通过 STLink 的 attach 只读核对得到：`CPUID=0x410fc241`、`DBGMCU_IDCODE=0x20036468`、Flash 128KB，与原理图中的 G431 相符。`0x468` 本身不能区分 G431/G441 和封装；板卡型号同时依据用户指定原理图。

## Codex 做了哪些工作

1. 查阅手册、原理图、GPIO/UART 与 Hall 例程，核对电源、PWM 和保护接入。
2. 分析已完成的 MATLAB TD3 训练与独立评估，确定该短训候选没有改善固定 PI 的误差，因此不批准用于真实电机闭环。
3. 从 Actor JSON 重新生成计算 C，使用 Arm Compiler 6.9 交叉编译 Cortex-M4F 硬浮点 RAM 镜像，检查加载地址和栈空间。
4. 暂停目标并备份原 Flash，系统复位后验证 TIM1 输出关闭，将网络与测试向量加载到 SRAM；执行期间屏蔽中断，不初始化 PWM 或应用增益。
5. 经 SWD 读取推理输出、CPU 周期和栈检查结果，与 MATLAB 参考逐组比较。
6. 确认原 Flash 逐字节保持一致，结束保持核心暂停；将计算结果和结论写入公开报告。

第一次尝试因调试库复位枚举名称不兼容，在加载前停止；修正为 pyOCD 0.45.1 的 `SYSRESETREQ` 后完成验证。该次中止同样没有修改 Flash。

## 实测结果

使用已公开的 `candidate-006` 模拟 Actor，网络 `10→16→16→2`，482 个 float 参数，共 1,928B。它只接受人工测试向量，输出没有连接到电机控制器。

| 验证 | 结果 |
|---|---|
| 40 组 MATLAB 参考输入 | 全部通过 |
| 最大动作绝对误差 | `1.862645149230957e-9` |
| 最大 Kp/Ki 绝对误差 | `0.0` |
| NaN / Infinity / 越界增益 | 三项均拒绝 |
| 单次推理周期（最小/最大/平均） | 11,508 / 11,628 / 11,559.525 |
| 栈涂色最大观测占用 | 456B，保留 1,024B，底部 64B 完整 |
| RAM 测试镜像 | 12,844B，包含数学库、向量表与测试输入 |
| 时钟和执行环境 | 复位后 `RCC_CFGR=0x5`：标称 HSI16 16MHz、AHB 不分频；RAM 执行、屏蔽中断 |
| 最终状态 | TIM1 输出关闭，核心暂停，原 Flash 内容一致 |

在此标称时钟下，最大观测周期约为 0.727ms。该数值不代表带 FOC 中断、Flash 等待、不同库/编译选项下的最坏执行时间。栈占用也只覆盖本次向量与异常输入。

## 训练结果的分析结论

6 轮真实 MATLAB TD3 更新得到 180 条经确认训练经验，Actor 权重变化 L2≈0.0882。独立测试关闭探索，用三个相同工况比较固定 PI 与候选：

- 平均归一化 RMSE：固定 PI `0.1716951212`，TD3 `0.1717127256`，候选约高 0.0103%；三个工况均没有降低误差。
- 两者在这些工况中均无超调、无故障；最重工况均达到 3A 模拟电流限幅，饱和占比约 2.67%。这来自模拟对象，不能作为真实板卡保护证据。
- 权重更新和 MCU 推理一致性证明训练/部署计算链路可运行，不能证明策略性能改善。

**Codex 的判断：保留固定 PI 基准；允许候选做无电机输出的 RAM 计算验证，不批准将这个模拟候选用于实机闭环。**

## 当前范围与后续接入

本次已完成实际 MCU RAM 部署与计算验证。未打开电机串口做训练，未形成真实电机经验，未应用网络增益，未写入 Flash，未验证电机闭环或独立硬件停机。

所查旧 VOFA 例程的 JustFloat 遥测和参数命令不能直接提供本训练器需要的完整时序/原子增益确认/租约。当前原 Flash 对应哪个源工程也尚未完整确认。下一步应接入 MCU 协议与保护模块，验证实际应用反馈、独立过流、急停、失联停机、温度/替代保护和已验证 PI 基准，再进行受限真实采集和候选评估。

**控制板当前保持暂停，原固件仍在 Flash。复位或断电重启会恢复原固件；恢复功率电源前须核对原应用的启动和保护状态。**此计算测试并未把板卡变成可直接运行 TD3 的电机固件。
