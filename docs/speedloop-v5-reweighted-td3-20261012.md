# 2026-10-12：增强惩罚 TD3 离线重训与准入

## 数据与训练

原有 17 次真实试验和新增 6 轮 A/B 试验重新审计，得到 194 个有实际增益应用和后续响应的动作窗口。固定划分为 150 个训练窗口、44 个验证窗口；重复 boot 会话、序号断裂、应用回读缺失和非 RunStage 窗口均不进入经验池。

重训同时保留旧奖励，新增：

- 峰值名义电流惩罚；
- 接近 1800 rpm 保护上限的惩罚；
- 电流饱和惩罚；
- 动作幅度惩罚。

训练使用 MATLAB R2024b、随机种子 7/17/27，每个候选 80 个训练 step。Ki 动作固定为 0，实际 Ki 保持 0.00144。

## 准入结果

三个种子的动作范围和增益范围均通过，但 Kp 动作方向不一致：一个种子给出正方向，两个种子给出负方向。由于离线数据不能证明新动作在电机上的反事实性能，候选没有获得部署许可。

重复实机 A/B 的均值也不满足准入条件：

- Actor Kp 的 RMSE 比基准 PI 高 3.39%；
- 峰值名义电流增加 0.0146 A；
- 峰值 Hall 转速增加 55.6 rpm。

因此当前决策为保持基准 PI、拒绝候选、不烧录 Actor。温度门、普通实机准入门和部署状态均未修改。

完整机器可读结果见 examples/speedloop-v5-real-20261012/reweighted-td3-20261012。
