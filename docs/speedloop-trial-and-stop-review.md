# SpeedLoop 单次试转与停机复核

2026-10-11，用户确认 24V/3A、电机空载、人员远离，并手动按 USER3。
当时板上运行 Codex 构建的 SpeedLoop 门控副本，未部署 TD3，模糊 PI 仍由原例程计算。

## 实际取得的证据

| 项目 | 单个暂停快照 |
|---|---|
| Hall 速度 | 约 1026 rpm（原例程换算，未以独立转速计校准） |
| 母线 | 约 24.1V（原例程 ADC 比例） |
| 三相电流 | 约 +0.066 / −0.022 / −0.088A（未校准的标称换算） |
| Hall 编码 | 4，单个有效状态 |
| Motor_state | 255 |
| TIM1 CCER / BDTR | `0x1555 / 0x0202B078`，三相使能且 MOE=1 |
| TIM1 Break 标志 | 快照 BIF=0 |

这些读数证明该镜像出现过电机转动。此次没有连续曲线，不能推断启动峰值电流、
Hall 六状态连续性、超调、稳定时间或误差改善，也没有形成 TD3 的状态—实际动作—响应经验。

## 停机流程发现的问题

读取工具在连接时先暂停核心，后续等待不形成连续采样窗口。
暂停 CPU 后 TIM1 仍可能运行；当时先暂停，再另行写 MOE/CCER 禁能，存在时间间隔。
最终关闭输出不等于这段过程具有独立、可靠的限时停机。记录不把这次操作描述为已验收的安全受限试验。

旧镜像缺少独立试验期限和失联租约；停止后软件启动标志仍为 255。
因此先关闭输出、暂停核心，要求物理断开 24V 后再复位清理。
用户确认断电后，复位运行约 300ms，随后再次禁能并停止 TIM1：

```text
Motor_state = 0
TIM1->CR1  = 0x00000130  // CEN=0；DIR 等状态位不代表输出开启
TIM1->CCER = 0x00000000
TIM1->BDTR = 0x02023078  // MOE=0
Core       = Halted
IA/IB/IC_Offset = 2023 / 2030 / 2026
```
