## 默认禁止运动的接入版本

适配层 [motor_td3_g431_adapter.c](../skills/motor-td3-serial-tuning/firmware/motor_td3_g431_adapter.c) 没有开启 PWM、启动电机或写入增益的分支，也没有远程解除锁定的接口。

- USER3 改为停机并锁存诊断故障；连续按键不会启动。
- 禁能先清 TIM1 MOE 和六路相位使能位，再清 `Motor_state`、`rtU.Motor_OnOff`。保留 CH4 的 ADC 触发配置；内部 OC4REF 触发不需要把相位输出打开。
- SysTick 每 1ms 独立执行禁能与协议故障检查，主循环 5ms 不更新进度会锁存故障。它仍依赖 MCU、中断和时钟正常工作；尚未验证中断长期被屏蔽时的独立硬件看门狗。
- FDCAN 接收中断最多取三帧，写入 64 帧缓冲；保留 MCU 接收时间，错误格式或溢出会禁能。前台分片解析和 SysTick 端点任务通过短临界区串行访问。
- 仅接收标准 ID `0x620`、经典 CAN、DLC=8、无 BRS；拒绝其他标准/扩展 ID 和远程帧。500 kbit/s 的原位时序保留。
- 发包使用 FIFO 剩余空间检查，每次轮询至多发送一帧；握手包有 50ms 排队期限，没有忙等发送。CAN 错误与 bus-off 会禁能并锁存。
- 原 UART 接收和 ADC 中断里的 UART DMA 遥测已从副本移除，避免第二条控制入口和高频发送占用。
- 初始化模型先于启动 ADC 中断；母线读取等待转换完成；零母线或无效母线时跳过模型计算，避免除零。Hall 周期为零或码为 000/111 时先禁能，不进入原除法。

这些改动只在新建的私有工程副本里发生，用户原目录没有改变。厂商工程、HEX 和私有照片没有上传。

## 诊断协议与数据缺口

身份为 `g431-foc-can-locked-v1`，配置为 `g431-foc-locked-v1`。锁定端点的能力位恒为 0，故障码为 `12`（未准备好）；真实训练器会拒绝这个握手。STOP 可以保持禁能，不能解除故障。

该示例没有温度采集代码，所以实际快照的温度明确为 `NaN`，不会伪造 30℃ 或产生 `0x621` 训练遥测。单独的原始诊断帧采用以下布局，均为小端；它们没有训练所需的动作对应关系，不得送入经验池。

| 标准 ID | 8 字节载荷 |
|---|---|
| `0x622` | schema:u8=1，故障:u8，flags:u16，原始 PB6..8 Hall 码:u8，保留:u8=0，注入 ADC 样本年龄毫秒:u16（饱和到 65535） |
| `0x623` | 实际存储 Kp:f32、Ki:f32 |
| `0x624` | 原母线测量 V:f32、三相最大绝对电流 A:f32 |
| `0x625` | 原 Hall 转速 rpm:f32、原速度积分输出 A:f32 |

flags：bit0 电流偏置采集完成，bit1 当前 Hall 码有效，bit2 硬件相位输出使能，bit3 温度有效（始终 0），bit4 诊断故障锁存，bit5 曾收到无效 Hall 捕获。四帧发送后等待 100ms；这个诊断组不是同步训练快照。原始 Hall 位顺序与原角度映射的位顺序不同，按明确布局解释。

boot 身份也没有猜测：本版本需要在复位后暂停核心，由调试器提供一次非零随机 `motor_td3_g431_debugger_boot_token`。它在初始化后消耗，不能重新使能任何功能。**这是诊断用接口；生产启动身份的独立生成仍待实现。**

## 构建与复现

详细命令见 skill 内的 [G431 接入说明](../skills/motor-td3-serial-tuning/references/g431-locked-integration.md)。构建器先校验已审计源码指纹，遇到其他修订直接拒绝，不在未知工程上盲目替换。

RAM 测试只打开 STLink，不打开 PCAN：复位并暂停 → 检查 PWM/GPIO 关闭 → 加载固定测试到 SRAM → 核验 SRAM → 运行 → 读取结果 → 复位并暂停 → 比较完整 Flash。期间只打开 TIM1 外设时钟，并在 MOE=0、引脚保持复位模拟模式的条件下给 CCER 设置测试位，检查共享函数确实能清除它们；**从不设置 MOE、不启动计数器、不配置功率引脚**。

## 开放真实训练前仍需完成

1. 接入实际温度观测或经验证的热保护方案，不直接删除配置校验。
2. 校准并验证比较器过流门槛、实际刹车响应、急停和独立硬件看门狗；24V/3A 电源限流不能代替相电流保护。
3. 实现生产 boot 身份、与该电机匹配的 Hall 超时/方向检查、真实基准和带来源的参数/运行边界。
4. 在速度环边界实现并验证无扰增益切换。这里 Ki 是连续增益，`Integrator_PREV_U` 已含 Ki×误差或抗饱和零值；不能重乘采样时间或只换两个数忽略积分状态和 NNSMC。
5. 安装并验证完整接入固件的 CAN 身份、真实观测与实际应用序号，再开始有界基准试验、旁路预测、固定候选比较和受限训练。
